# X1 Growth Engine | Digital Dominance transition
**Decision:** X1 Operating System replaces DIGITAL DOMINANCE as the platform identity and operating umbrella, not as a retroactive deletion or authorization to migrate all its data.
## Classification
PRESERVE: canonical `XTREME-SYSTEMS/digital-dominance` original admin/generator patterns, existing provider/location facts, verified Google integrations, URL pipelines and compliance validators.
EXTRACT: scoring, useful PageSpec templates, SEO validator, preview/approval wizard, publishing receipts and CRM lead interfaces.
REFACTOR: provider-specific coupling, broken Base44 APIs, copy-pasted site/site schema and model calls to one owned runtime.
MERGE: only when newer X1 models pass measured parity; keep branch/owner provenance.
QUARANTINE: thin/duplicative/unverified local pages and fake business details until reviewed.
RETIRE: only after explicit disposition/rollback approval; no blanket deletion.

## Distinct product modules
- X1 Avatar Studio = synthetic presenters, voice, video and live interactive agents.
- X1 Website Factory = original value-driven site products, preview approval and client portals.
- X1 Growth Engine = evidence-driven SEO/AEO/local search analytics and publishing.
- X1 Client OS = CRM, lead capture and opt-in social automation.
- X1 Agent Engineering = governed source-first autonomous coding runtime.

## Migration rule
Exact donor SHA -> integration contract -> original proof tests -> isolated implementation -> independent validation -> explicit protected release. Do not propagate duplicate city/service pages or fabricate local presence, prices, ratings or reviews. NearMe transactional vs NearYou decision-support roles remain separate until approved SiteSpec.
