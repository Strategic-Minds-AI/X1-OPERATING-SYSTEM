# X1 Avatar Studio | Product + HeyGen-category benchmark
## Product thesis
One multi-tenant platform to create, manage and deploy consent-based digital humans for video production, interactive livestream conversation and enterprise agents. Eden is launch identity **one**, not a hardcoded product architecture. This must outperform generic template builders in visual craft, admin clarity and ownership, not make unverified claims of generative superiority.

## Roles
Operator/admin: create projects, approve identity enrollments, control models, costs, publish gates.
Tenant owner: workspace, billing and membership in authorized scope.
Creator: storyboarding, voice selection, consented source media, create/draft sessions.
Viewer/client: streamed digital human with clear AI disclosure, optional text transcript.
Verifier: independent evaluation, signed receipts, rollback authority.

## Product pillars and acceptance
1. **Avatar Library:** source identity upload, KYC/consent/provenance receipt, versioned assets, approved/enrolling/trained/deactivated states; tenant-isolated metadata; source material never publicly accessible by default.
2. **Avatar Builder:** photo/video workflow, crop/quality validation, voice enrollment, realistic idle motion/eye expression, separated output styles, selectable aspect/resolution, preview/approval process. Initial studio supports only local drafts.
3. **Video Creator:** script editor, media references, scenes, selected avatar/voice, multilingual caption/translation only when model validated, brand presets, versions, server-render queue, playback, export, export disclosure metadata.
4. **Live Avatar:** actual audio/video stream, user microphone, spoken response via AI Gateway, live head/eyes/mouth, barge-in, latency/AV drift monitoring, pause/stop and 1-click resource termination.
5. **Voice Lab:** consent/identity review, voice direction, legally approved voice clone when explicitly authorized, synthetic default voices, listening A/B tests.
6. **Avatar API/SDK:** signed ephemeral session tokens, JS SDK, rate limit and usage billing, audit trails, health/dispose, webhook with validated signatures.
7. **X1 Autonomous Engineering:** proposal -> packet -> approved queue -> lease -> code branch -> CI -> independent validation -> receipt; safe autonomous advancement only.
8. **X1 Growth Engine:** vetted website publishing and acquisition module, preserving Google index eligibility and anti-doorway restrictions. Never confuse '100 websites' with '100 index-eligible unique sites'.

## Milestone levels
- M0: full visual studio **without claiming video generation**.
- M1: real authenticated asset/memory and nonbillable job flow.
- M2: first genuine synthesized video with licensed model and consented source.
- M3: first real-time conversation with synchronized video and interrupt.
- M4: multi-tenant creator workflows, latency and security certified.
- M5: paid/customer release gated by operator and independent validation.

## Benchmark scorecard (measure, do not invent)
HeyGen/LiveAvatar features: creator identity pipeline, voice quality, animation fidelity, facial stability, first-response latency, barge-in, video export, localization, concurrent sessions, API UX, predictable per-minute cost. Record baseline source, consent, date, test script, video sample, p50/p95 metrics and qualitative blind reviewer scores. Equality to competitor is UNKNOWN until objective tests exist.

## Metrics
Activation: draft-to-consented-identity rate; successful trained/validated avatar rate.
Quality: lip-sync, identity consistency, jitter, frame drops, speech-to-first-audio p50/p95, A/V drift.
Reliability: fatal sessions, orphaned GPUs, fallback success, renderer cold start, queue retry, idempotent work.
Economics: cost per generated minute and cost per live-session minute, full infra attribution.
Safety: unconsented identity attempt block rate, rate-limit abuse, tenant leakage, unauthorized tool calls.
