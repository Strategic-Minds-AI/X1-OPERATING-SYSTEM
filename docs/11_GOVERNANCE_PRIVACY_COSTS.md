# X1 | Control gates, content authenticity and business economics
- Consent: each avatar identity and voice require verified authority, purpose-specific release, revocation, auditable identity linkage and protected media storage. Never let a creator generate deceptively impersonating people without permission.
- Disclosure: synthetic video/audio should be transparently identified where relevant; watermark/export metadata policies documented per use case.
- Provider: verify every code/model/weight/dataset and dependency commercial license before SaaS; a GitHub MIT repo does not automatically grant rights over all pretrained checkpoints.
- Privacy: face/voice are potentially sensitive biometric material. Define consent, notice, retention, deletion, processing locations, legal review, monitoring and incident response, with minors restricted by policy.
- AI output quality: brand fidelity, voice identity, bias/abuse testing, visible controls and operator escalation.
- Spend: fixed monthly platform fees + Gateway token/audio consumption + GPU time + media egress + storage + worker compute + monitoring. Track cost per rendered minute, live minute, tenant and successful onboarding.
- User-approved resource budget is required before opening paid GPU instances, subscriptions, new Supabase billable projects or live model training. Prevent uncapped workers.
- Agents may plan, draft, branch commit, test, open PR and generate receipts. They may NOT silently publish production, provision accounts, grant IAM access, post socially, email customers, change DNS, rotate secrets, merge protected branches or incur spend.
- Digital Dominance legacy pSEO modules must pass Google helpful-content/index-eligibility and anti-doorway checks for every proposed indexable URL; never promise first-page ranking.
