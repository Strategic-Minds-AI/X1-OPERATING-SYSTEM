## P1: one real synthetic customer journey
- [ ] GPT sentence + Eden consented onboarding -> signed scoped mission API in staging.

- [ ] Client portal: tenant-owner auth, CRM/lead inbox, analytics, digital business card, content/media.

- [ ] Provide **verified working frontend preview URL** and receipt. Do not call ready until actual evidence exists.

## P2: social/AI operating business
- [ ] Reuse Be Near Me media gallery, short-form video, licensed creator templates.
- [ ] Draft calendar/social channels: TikTok, YouTube, Instagram, Facebook where APIs and account scopes permit.
- [ ] Approved-once automation bounded by exact channel, immutable media, calendar window, and revocable permission.
- [ ] AI SEO/AEO/GEO daily draft recommendations, no ranking guarantees, beneficial unique content.
- [ ] Support agent and warranty portal with remote access opt-in and incident receipts.

## P3: scale with evidence
- [ ] One paying-customer-ready system and operator-approved release.
- [ ] Ten independently verified preview sites; measure costs, conversion, latency and failures.
- [ ] Capacity stress 100/500/2000 controlled. Increase concurrency only after provider quotas, tenant isolation, independent browser QA, budgets and single heartbeat verified.
- [ ] Digital Dominance remains an internal engine, hidden from client dashboards.

## Blocks today
Real code writer, X1 authorization, duplicate reconciler ownership, tenant RLS security, live Eden/voice integration, and triple-pass frontend QA are unproven. Do not equate this bootstrap with production-ready deployment.
